# Insurance Claims - Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on an Insurance Claims dataset using Python.

## Objectives
- Understand the insurance claims dataset.
- Identify and handle missing values.
- Remove duplicate records.
- Clean inconsistent categorical values.
- Detect outliers.
- Visualize data using graphs.
- Identify patterns and relationships.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Data Preprocessing
- Removed duplicate rows and columns.
- Handled missing values using Median and Mode.
- Removed rows with missing target values.
- Removed unnecessary ID column.
- Cleaned inconsistent policy categories.
- Checked outliers using the IQR method.

## Data Visualization
- Fraud Flag Distribution
- Claim Amount Distribution
- Policy Type Distribution
- Policy Holder Age vs Claim Amount
- Correlation Heatmap
- Boxplot for Outlier Detection

## Final Dataset
- Total Records: 221
- Total Features: 6
- Missing Values: 0
- Policy Categories: Auto, Home, Life, Health

## Conclusion
EDA helped us understand the insurance claims data, identify patterns, clean inconsistent data, and visualize important relationships.

The cleaned dataset is saved as a CSV file.
